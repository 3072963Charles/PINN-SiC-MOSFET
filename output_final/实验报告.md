# 4H-SiC功率MOSFET SPICE紧凑模型参数提取 — 实验报告

**基于物理信息神经网络(PINN)的SPICE Level-3参数逆向提取**

---

## 项目概述

### 研究目标

针对1.2kV 4H-SiC垂直DMOSFET器件，利用物理信息神经网络(PINN)从TCAD仿真数据中自动提取SPICE Level-3紧凑模型的物理参数，生成可直接用于电路仿真的SPICE .SUBCKT/.MODEL文件，模型精度需优于前人的~5% MAPE目标。

### 技术路线

```
TCAD数据 → PINN混合模型(SPICE Level-3物理 + NN残差修正) → 参数提取 → SPICE模型生成 → 精度验证
```

### 核心创新

- **物理残差架构**：`I_total = I_phys × exp(δ_log)` — 乘法修正保证梯度畅通且电流恒为正
- **可微分SPICE Level-3模型**：13个可训练物理参数，纯PyTorch实现，支持自动微分
- **双端对称传导**：支持V_DS < 0的反向导通，通过Gummel对称性测试
- **亚阈值专项损失**：3倍加权的亚阈值log-space MSE损失，针对性提升弱反型精度

## 模型架构

### 整体结构

```
输入: [V_GS, V_DS, V_BS, T]  (4维)

┌──────────────────────────────────────┐
│  PINN骨干网络 (8层MLP, 256维隐藏层)    │
│  Swish激活 + LayerNorm + Dropout(0.05)│
│  残差连接 + 单调性约束                 │
└──────────┬───────────────────────────┘
           │
     ┌─────▼──────┐
     │ δ_log 预测  │  ← 对数域修正量 (最终层零初始化)
     └─────┬──────┘
           │
     ┌─────▼──────────────────────────┐
     │  SPICE Level-3 物理模型        │
     │  13个可训练参数                │
     │  I_phys = f(V_GS, V_DS, T)    │
     └─────┬──────────────────────────┘
           │
     ┌─────▼──────┐
     │ I_total =  │
     │ I_phys ×   │
     │ exp(δ_log) │  ← 乘法修正
     └────────────┘
```

### 损失函数

```
L_total = L_data_log + 3.0×L_data_sub + L_data_lin + λ_phys×L_physics + λ_smooth×L_smooth + λ_mono×L_mono
```

| 损失分量 | 公式 | 作用 |
|----------|------|------|
| L_data_log | MSE(log10(I_pred), log10(I_true)) | 全量程对数精度 |
| L_data_sub | MSE(log(I_pred), log(I_true)) × mask(I<1e-6A) | 亚阈值专项加权(3x) |
| L_data_lin | MSE((I_pred-I_true)/I_true) × mask(I>1e-8A) | 强反型线性域精度 |
| L_physics | mean(δ_log²) | 物理一致性(惩罚大幅修正) |
| L_smooth | mean(d²I/dV_DS²) | I-V曲线平滑性 |
| L_mono | mean(max(0, sign(V_GS1-V_GS2)×(I2-I1))) | V_GS单调性 |

## Gummel对称性测试(GST)

GST验证器件的源漏交换对称性，确保模型在交流/瞬态仿真中不会产生伪影：

```
测试条件: V_GS=10V, V_DS∈[-0.1, 0.1]V, T=300K
对称性公式: I_D(V_GS, V_DS) = -I_D(V_GS-V_DS, -V_DS)

结果:
  GST_RMSE:           5.0×10⁻⁸ A
  GST相对RMSE:        0.67%  (< 1%阈值)
  V_DS=0处电流:       ≈ 0 A  ✓
  符号正确性:          通过    ✓
```

模型通过源漏交换对称性验证，可安全用于同步整流等双向导通电路仿真。

## 关键问题与解决方案

### 训练过程中的数值问题

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| 初始训练输出全NaN | 加法修正I_total=I_phys+ΔI在ΔI为负时产生负电流，clamp杀死梯度 | 改为乘法修正 I_total=I_phys×exp(δ_log) |
| MAPE恒为100% | 全部输出层零初始化阻塞梯度传播 | 仅对最终输出层零初始化 |
| 物理参数崩塌(KP→0.01) | Stage-1物理预热推动参数远离真值 | 去除Stage-1，直接联合训练 |
| 周期性MAPE尖峰 | CosineAnnealingWarmRestarts LR重启 | 改用CosineAnnealingLR单调衰减 |
| V_DS=0处I_D≠0 | 饱和区权重在V_DS→0时残留2% | 缩窄过渡带宽度 |
| 亚阈值MAPE 13.4% | 亚阈值样本在总损失中权重不足 | 添加3×亚阈值专项log-space损失 |

### 模型架构迭代

| 版本 | 关键改动 | MAPE |
|------|----------|------|
| output_test (初始) | 加法修正 + Stage-1预热 | NaN |
| output_test3 | 乘法修正初版 | 100% |
| output_test7 | 去除Stage-1 + 分离学习率 | 2.70% |
| **output_final** | +亚阈值损失 + 饱和过渡修复 + GST修复 | **0.96%** |
